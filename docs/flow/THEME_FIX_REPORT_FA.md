# اصلاح تم پیش‌فرض Flow

صفحهٔ اصلی اکنون در زمان build با ساختار نهایی Flow ساخته می‌شود؛ لوگو، تصویرها و فرم‌ها برای تغییر شکل صفحه منتظر `theme.js` نمی‌مانند. اسکریپت صفحه فقط تعامل ناوبری را متصل می‌کند.

خوانشگر پنج‌نمونه‌ای قبل از runtime اصلی نصب می‌شود تا اولین نمایش سند با وضعیت و رنگ درست انجام شود. یک لایهٔ رنگی مستقل، خوانشگرهای قدیمی و استان‌ها را پوشش می‌دهد. registry پنج‌تایی حفظ شده و مهندسی برق همچنان holdout قالب است.

قطب‌نما و مقاله‌ها پیش از انتساب `srcdoc`، توکن‌های Flow و CSS آمادهٔ نمایش تیره را دریافت می‌کنند. CSS اصلی برای چاپ حفظ می‌شود و نسخهٔ رنگی فقط در `@media screen` فعال است. رنگ inline با fallback اصلی برای چاپ نگه داشته می‌شود. رنگ‌های معنی‌دار نوار امتیاز و پیشرفت حفظ شده‌اند و کنترل‌های دارای زمینهٔ accent روشن، نوشتهٔ تیره دارند.

## حفظ منبع و رفتار

- منبع مبنا: `566a137a9903c06ea499a25be0e1a821cec86685`.
- `public/index.html` تغییر نکرده است؛ SHA256:

  ```text
  ebb69da2b9154a4ad1ca578bf6bb9409aba4846715260cd7d706964b35dfdee2
  ```

- payloadهای خام JSON، تصاویر embedded، قطب‌نما، bridge و ownership در خروجی با منبع مقایسه می‌شوند.
- متن و hrefهای authored content پنج رشته با baseline برابرند. متن، لینک‌ها و scriptهای authored هر ۲۲ مقاله نیز قبل از اجرای iframe برابرند.
- الگوریتم آزمون، پرسش‌ها، امتیازدهی، persistence و رویدادهای اصلی تغییر نکرده‌اند.
- منبع مستقل مقاله‌ها و نسبت‌دادن محتوا به آریس حفظ شده‌اند.
- parse5 فقط به dependencyهای build اضافه شده است؛ runtime مرورگر dependency جدیدی ندارد. PostCSS موجود، فقط declarationهای رنگی CSS را آماده می‌کند.
- فایل‌های تولیدی `public/flow-preview.html` و `dist/**` در Git ثبت نمی‌شوند. config، نام Worker، route و فرمان انتشار تغییر نکرده‌اند.

## اعتبارسنجی

تاریخ بررسی: ۲۰۲۶-۱۰-۰۲.

| بررسی | نتیجه |
| --- | --- |
| `npm run lint` | موفق |
| `npm run typecheck` | موفق |
| `npm run test` | ۹ تست موفق؛ شامل ساخت fixture در checkout تازه |
| `npm run build` | موفق |
| Playwright | ۱۸ تست موفق |
| `npm run check:cloudflare` | dry-run موفق |
| `npm run test:cloudflare` | بایت و hash خروجی، redirect و 404 واقعی موفق |

تست‌های مرورگر شامل صفحهٔ اولیه بدون JS، مسدودکردن فایل‌های deferred، هر پنج adapter، holdout، close/Back/Forward/focus، اسکرول جدول و عرض‌های ۳۲۰، ۳۹۰ و ۷۶۸ پیکسل است. هر ۳۴۲ رشته و ۳۱ استان در موبایل باز می‌شوند و surface تیره و نبود overflow بررسی می‌شود. تمام ۲۲ مقاله از نظر تم اولیه و سطوح روشن، حفظ محتوا و منابع بررسی می‌شوند.

دو قالب متفاوت مقاله از نظر computed colors چاپ با سند اصلی مقایسه شده‌اند. خوانایی دکمه‌های اصلی بومی‌گزینی و نمایان‌بودن رنگ نوار امتیاز قطب‌نما تست مستقل دارند؛ تست نوار، CSS واقعی گزارش را بدون ثبت پاسخ کاربر بررسی می‌کند.

در نمونهٔ اندازه‌گیری محلی با PerformanceObserver، CLS صفحهٔ اصلی حدود **۰٫۰۲۹ دسکتاپ** و **۰٫۰۸۰ موبایل** بود. این یک نمونهٔ آزمایشگاهی است و اندازه‌گیری Production یا p75 نیست. انیمیشن‌های ورود موجود در قطب‌نما حفظ شده‌اند.

خروجی نهایی HTML هنگام بررسی **۲۱٬۲۵۲٬۱۸۵ بایت** و زیر محدودیت ۲۵ MiB برای هر asset بود. قرارداد بایت‌های کامل با Workers محلی تأیید شد. build و تست‌های دارای generator به‌ترتیب اجرا می‌شوند تا تغییر فایل‌های watched باعث قطع پاسخ آزمون نشود.

## بازبینی و محدودیت

بازبینی مستقل سه ایراد مهم مربوط به چاپ، contrast دکمه و نوار امتیاز پیدا کرد. هر سه با تست شکست‌خوردهٔ بازتولید، اصلاح و اجرای سبز suite بررسی شدند.

`FlowDocuments.theme()` عمداً در مسیر فعلی سند خام دریافت می‌کند. اعمال دوبارهٔ آن به HTML از قبل themed قرارداد عمومی پشتیبانی‌شده‌ای نیست و خطای تعداد style می‌دهد؛ مسیرهای بستن و بازکردن دوباره، سند خام را مصرف می‌کنند و تست شده‌اند.

این تغییر برای بررسی روی branch آماده شده است؛ Production در این مرحله منتشر نشده است.
