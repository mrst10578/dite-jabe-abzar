# تحویل قالب صفحات داخلی Flow به Luna

## نمونهٔ مرجع

صفحهٔ واقعی **مهندسی کامپیوتر**، با تمام محتوای فعلی:

`/flow-preview.html#major=computer-engineering`

در خروجی Cloudflare همان پرونده از مسیر `/#major=computer-engineering` باز می‌شود. این سند نشانهٔ انجام دیپلوی نیست.

این مرحله فقط یک نمونه است. قالب استان‌ها، مقالات و باقی رشته‌ها هنوز تعمیم داده نشده است.

## فایل‌های اصلی و قرارداد قالب

| فایل / نشانه | مسئولیت |
| --- | --- |
| `public/flow/reader.css` | ظاهر خواننده؛ تمام قواعد زیر `body[data-flow-reader="major"]` محدود شده‌اند |
| `public/flow/reader.js` | فعال‌سازی نمونه، بسته‌بندی بخش‌های تخت، تزئین سربرگ و برند رابط |
| `public/flow/tokens.css` | رنگ‌ها، فونت و مقیاس مشترک Flow |
| `public/flow/theme.css` و `theme.js` | صفحهٔ اصلی موجود؛ مرجع هویت بصری |
| `scripts/build-flow-preview.mjs` | افزودن فایل‌های قالب به خروجی؛ فایل اصلی بازنویسی نمی‌شود |
| `tests/e2e/flow-reader.spec.ts` | حفظ محتوا، رفتار، تاریخچه و عرض‌های مختلف |
| `docs/flow/references/reader-desktop.webp` و `reader-mobile.webp` | تصاویر نمونهٔ اجراشده |
| `.page[data-aris-profile="computer-engineering"]` | شناسهٔ پایلوت؛ نام نمایشی یا متن فارسی معیار تشخیص نیست |
| `data-flow-reader-template="1"` | جلوگیری از تزئین تکراری همان سند |
| `.flow-reader-section` | بسته‌بندی H2 تخت همراه با محتوایش، بدون کپی‌کردن گره‌ها |

رویدادهای جست‌وجو، تغییر hash، تاریخچه، جدول‌ها و جزئیات توسط موتور اصلی اجرا می‌شوند. Observer فقط فرزندان مستقیم `#major-document` و تغییر `hidden` خواننده را می‌بیند. برای تعمیم، ساختار هر خانواده باید جداگانه بررسی شود؛ همهٔ ۳۴۲ رشته الزاماً `.page[data-aris-profile]` یا چیدمان مشابه ندارند.

یک اصلاح ناوبری مخصوص نمونه وجود دارد: موتور اصلی برای تیتر تختِ بازار کار، `closest("section")` را پیش از ساخت ظرف‌های جدید اجرا می‌کرد و خود خواننده را هدف می‌گرفت. قالب، همان بخش واقعی منتخب موتور (در این نمونه «درآمد و عوامل مؤثر بر آن») را به `data-aris-section="market"` متصل می‌کند. دیگر دکمه‌های فهرست همان listenerهای اصلی را دارند. این رفتار در تست محل پرش بررسی می‌شود.

## معیار ظاهری

- زمینهٔ سرمه‌ای `--flow-bg`، سطح پنل `--flow-surface`، متن روشن `--flow-text`؛ فیروزه‌ای برای عملیات و سبز برای تأکید. طلایی فقط برای جزئیات محدود.
- فونت Vazirmatn موجود، RTL، متن ۱۶ پیکسل دسکتاپ و ۱۵ پیکسل موبایل با فاصلهٔ سطر حدود ۲؛ تیترهای روشن، عرض خواننده حداکثر ۱۱۲۰ پیکسل.
- سربرگ داخلی کوتاه، برگشت واضح، معرفی رشته با تصویر کتاب موجود در دسکتاپ. تصویر تزئینی روی موبایل پنهان می‌شود تا متن مقدم باشد.
- فهرست شش‌تایی اصلی با همان دکمه‌ها و listenerها؛ در موبایل اسکرول افقی فقط داخل فهرست و جدول‌ها مجاز است.
- کارت‌های خلاصه، بخش‌های متن، مقایسه، جدول و منابع باید هم‌خانواده باشند. صفحات متن‌محور نیاز به تکرار اژدهای بزرگ صفحهٔ اصلی ندارند.
- نام رابط و دعوت به کانال: **Flow** و `https://t.me/Flow_Konkour`. لوگوی بالا سمت راست فقط انگلیسی باشد.
- ارجاع نویسنده، منابع، تاریخ بازبینی و اشاره‌های تحریری به آریس حفظ شوند. جایگزینی سراسری «آریس» در متن مجاز نیست؛ فقط بلوک‌های تبلیغاتی تولیدشدهٔ رابط تغییر برند می‌دهند.

## مسیر پیشنهادی تعمیم

۱. همین نمونه را در دسکتاپ و موبایل باز کن و کد را بخوان. شکل واقعی چند رشتهٔ متفاوت را بررسی کن: مهندسی، پزشکی، هنر، انسانی و یک سند طولانی با تصاویر/جدول‌ها.

۲. ظاهر رشته‌ها را با adapterهای کوچک متناسب با خانوادهٔ DOM تعمیم بده. صرفاً حذف allowlist برای همهٔ صفحات کافی نیست. استایل‌ها در محدودهٔ خواننده بمانند و هنگام بستن/تغییر سند پاک شوند.

۳. استان‌ها را با همان توکن‌ها، ولی ساختار متناسب با فصل‌ها، شهرها و دانشگاه‌ها طراحی کن. سپس مقالات را با عرض متن و فهرست متناسب با محتوای آموزشی هماهنگ کن. موتور فعلی و محتوای کامل هر سه گروه حفظ شود.

۴. بعد از بررسی نمونه‌های هر خانواده، فعال‌سازی گسترده انجام بده. هیچ صفحه‌ای با محتوای کوتاه‌شده یا دادهٔ ساختگی جایگزین نشود.

## پذیرش و بررسی

- `public/index.html` باید دقیقاً ثابت بماند. SHA256 مرجع: `ebb69da2b9154a4ad1ca578bf6bb9409aba4846715260cd7d706964b35dfdee2`.
- تیترها، پاراگراف‌ها، لیست‌ها، متن جدول‌ها و href منابع قبل/بعد برابر باشند. تست موجود این مقایسه را برای نمونه انجام می‌دهد.
- باز کردن از جست‌وجو، لینک مستقیم، reload، بستن، Back/Forward و رفتن از سربرگ به جست‌وجو بررسی شوند. تزئین تکراری یا محتوای باقی‌مانده از سند قبلی وجود نداشته باشد.
- مقایسه و منابع باز/بسته شوند؛ جدول‌های عریض از سمت راست و داخل ظرف خود اسکرول شوند؛ محل پرش زیر سربرگ و فهرست ثابت قرار بگیرد.
- عرض‌های ۳۲۰، ۳۹۰، ۷۶۸ و دسکتاپ بررسی شوند. document بیرون‌زدگی افقی نداشته باشد. کنتراست، focus و کلیدهای صفحه‌کلید حفظ شوند.
- وابستگی جدید برای این تغییر لازم نیست. خروجی Next و Cloudflare باید هر دو همین UI را ارائه کنند.
- بررسی‌های ریپو: `npm run lint`، `npm run typecheck`، `npm run test`، `npm run build`، `npm run test:e2e` و `npm run check:cloudflare`. CI علاوه بر این، روتینگ واقعی Worker را بررسی می‌کند.
- تصویر دسکتاپ و موبایل از هر خانواده به گزارش نهایی اضافه کن. پایان کار، موارد انجام‌شده و محدودیت‌های واقعی را مشخص کن؛ آماده‌بودن build را به‌جای دیپلوی زنده اعلام نکن.

## پرامپت آماده برای Luna

```text
روی ریپوی mrst10578/dite-jabe-abzar کار کن. قالب Flow برای صفحهٔ واقعی مهندسی کامپیوتر آماده است. ابتدا docs/flow/LUNA_READER_ROLLOUT_FA.md، public/flow/reader.js، reader.css، tokens.css و تصاویر reader-desktop.webp و reader-mobile.webp را بخوان و نمونهٔ /flow-preview.html#major=computer-engineering را باز کن.

هدف: فقط UI صفحات داخلی رشته‌ها، استان‌ها و مقالات را با همین هویت Flow یکدست کن. محتوا، داده‌ها، منابع، جست‌وجو، URL/hash، تاریخچه و رفتار موجود حفظ شوند. لوگوی سربرگ فقط Flow انگلیسی باشد. متن اصلی و اعتبار نویسنده را تغییر نده و public/index.html را بازنویسی نکن.

ابتدا ساختار واقعی نمونه‌های متفاوت هر خانواده را بررسی کن، سپس قالب را با adapterهای کوچک تعمیم بده؛ صرفاً allowlist را حذف نکن. از دارایی‌های موجود استفاده کن. صفحهٔ اصلی تأییدشده را حفظ کن. رشته، استان و مقاله باید در رنگ، تایپوگرافی و عملیات هماهنگ باشند، اما ساختارشان با محتوای خودشان تناسب داشته باشد.

تست برابری محتوای قبل/بعد و تست رفتار موجود را به نمونه‌های جدید گسترش بده. موبایل ۳۲۰ و ۳۹۰، تبلت ۷۶۸ و دسکتاپ، جدول‌های عریض، فهرست ثابت، لینک مستقیم، reload، Back/Forward و برگشت به جست‌وجو را بررسی کن. همهٔ بررسی‌های تعریف‌شدهٔ ریپو و Cloudflare را اجرا کن. نتیجه را در یک PR با تصاویر دسکتاپ/موبایل و گزارش تست تحویل بده. دیپلوی زنده را فقط با نتیجه و آدرس واقعی اعلام کن.
```
