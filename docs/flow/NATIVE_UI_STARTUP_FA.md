# تکمیل ظاهر بومی Flow و شروع سریع‌تر

## تغییرهای قابل مشاهده

- قطب‌نمای انتخاب رشته در ترتیب راست‌به‌چپ پیش از کارت راهنما قرار دارد؛ در موبایل نیز بالاتر است. دکمهٔ «مطالعهٔ راهنماها» از کارت راهنما حذف شده است.
- تزئینات CSS سه خانوادهٔ `intro-badge`، `final-note` و `share-panel` دیگر نشان A تولید نمی‌کنند. این حذف شامل چاپ نیز می‌شود؛ متن علمی و رنگ‌های اصلی چاپ حفظ شده‌اند.
- نوارهای فلزی کارت‌های مقاله از متغیرهای طلایی قدیمی به رنگ‌های سبز و فیروزه‌ای Flow تبدیل شده‌اند. نوار پیشرفت خوانندهٔ مقاله نیز همین رنگ‌ها را دارد. شمارنده‌ها، برچسب پاسخ و رنگ‌های دارای معنای هشدار یا امتیاز حذف نشده‌اند.
- صفحهٔ آغازین یک وضعیت سبک Flow نشان می‌دهد و با آماده‌شدن کنترل‌ها کنار می‌رود. پس‌زمینه هنگام انتظار از دسترس کیبورد و خوانندهٔ صفحه خارج است. تأخیر طولانی گزینهٔ تلاش دوباره می‌دهد؛ اگر دریافت دیرتر کامل شود، پوشش خودکار کنار می‌رود. حالت بدون JavaScript زیر این پوشش نمی‌ماند.

## علت کندی و اصلاح دانلود

در بررسی نسخهٔ قبلی با Chromium، کش خالی، عرض ۳۹۰ پیکسل، تأخیر ۸۰ میلی‌ثانیه و دانلود ۱ مگابایت در ثانیه، نمایش اولیه ۱٫۴ ثانیه و آماده‌شدن صفحه حدود ۸ ثانیه بود. تنها یک اجرای طولانی JavaScript به مدت ۷۷ میلی‌ثانیه ثبت شد؛ عامل اصلی حجم دانلود اولیه بود.

۲۲ سند کامل مقاله، سند قطب‌نما و تنظیمات قالب هر سند داخل پاسخ اولیه قرار داشتند. اکنون هر سند به همراه قالب خودش با اولین بازکردن دریافت می‌شود. متادیتا و نمایهٔ کامل جست‌وجوی مقاله‌ها همچنان از ابتدا آماده‌اند؛ جست‌وجو به شبکه نیاز ندارد. دریافت موفق در همان نشست ذخیره می‌شود و بازکردن مجدد دانلود ندارد.

HTML اولیه از ۵٬۸۵۶٬۲۱۸ به ۲٬۲۳۵٬۵۵۹ بایت رسید؛ حدود ۶۲٪ کاهش دیگر. تصاویر تزئینی زیر صفحه اولویت پایین و بارگذاری تنبل دارند. لوگو و تصویر اصلی برای نمایش نخستین همچنان اولویت مناسب دارند.

مقاله ابتدا با وضعیت بارگذاری باز می‌شود؛ خطا امکان تلاش دوباره دارد. تعویض سریع یا بستن مقاله، پاسخ قدیمی را وارد خواننده نمی‌کند. قطب‌نما از بارگذاری و تلاش مجدد بومی خود استفاده می‌کند. دریافت معطل پس از ۲۰ ثانیه پایان می‌یابد تا امکان بازیابی وجود داشته باشد.

## حفظ محتوا و بررسی

منبع اصلی `public/index.html` با SHA-256 زیر تغییر نکرده است:

`ebb69da2b9154a4ad1ca578bf6bb9409aba4846715260cd7d706964b35dfdee2`

همهٔ ۲۳ سند خروجی هنگام build با سند اصلی مقایسه می‌شوند؛ داده‌ها، اسکریپت‌های علمی، امتیازدهی و APIهای موجود حفظ شده‌اند. فایل‌های استخراج‌شده نام مبتنی بر hash دارند و با همان استقرار منتشر می‌شوند.

بررسی‌ها: lint، TypeScript، ۲۷ تست واحد، build تولیدی، ۴۱ تست مرورگر، dry run Wrangler و آزمایش Workers برای HTML، redirect، 404 و checksum تمام ۲۳ سند، ۱۸۶ تصویر استان و MP3. تست‌های مرورگر همهٔ ۲۲ مقاله، ۳۴۲ رشته و ۳۱ استان را پوشش می‌دهند؛ همچنین انتقال واقعاً متوقف‌شدهٔ HTML، اینترنت ناموفق، تلاش دوباره، نتیجهٔ قدیمی پس از تعویض/بستن، چاپ، نمایش موبایل و حالت بدون JavaScript بررسی شده‌اند.
