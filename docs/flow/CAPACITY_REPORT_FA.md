# ابزار مستقل ظرفیت پذیرش

مسیر ابزار: `/capacity/` در Worker فعلی `entekhab-reshte`.
کارت صفحهٔ اصلی فقط لینک ورود است؛ ابزار در صفحهٔ خودش اجرا می‌شود.

ابتدا انتخاب گروه تجربی، ریاضی یا انسانی الزامی است. سپس رشته‌ها به ترتیب
حروف الفبای فارسی و دانشگاه‌های مرتبط با همان رشته نمایش داده می‌شوند.
انتخاب چند دانشگاه، جست‌وجوی دانشگاه، انتخاب همهٔ گزینه‌های قابل مشاهده،
پاک‌کردن انتخاب‌ها و تغییر گروه در دسترس هستند. تغییر رشته یا گروه، انتخاب
دانشگاه‌ها و نتایج قبلی را پاک می‌کند.

جدول از ۱۴۰۵ به ۱۴۰۱ مرتب است. سال ۱۴۰۵ برای هر سه گروه تجربی، ریاضی و انسانی فعال است. نبود داده در سال‌های
قدیمی «ثبت نشده» است؛ عدد صفر فقط از ردیف صریح ظرفیت صفر حاصل می‌شود.
مجموع ظرفیت شامل تمام دوره‌ها، جنسیت‌ها، نیمسال‌ها و شرایط موجود است؛ جزئیات
ردیف‌ها و منابع زیر جدول قابل مشاهده‌اند. ظرفیت اعلام‌شده، شمار افراد واقعاً
پذیرفته‌شده نیست. پوشش شیمی تجربی فقط روزانهٔ استان تهران است و در UI اعلام می‌شود.

## یکدست‌سازی نام دانشگاه‌ها

املای خام بعضی دانشگاه‌ها در دفترچه‌ها متفاوت استخراج شده است؛ مانند
«اسالمی/اسلامی» و «گیالن/گیلان». مدل مشترک `public/capacity/model.js` نام‌ها را
در فهرست انتخاب، جست‌وجو، اعتبارسنجی، جمع ظرفیت و نمایش نام دانشگاه/محل تحصیل
یکدست می‌کند. املای قدیمی در جست‌وجو هم به نام صحیح می‌رسد.

اصلاح‌ها شامل ۱۴ غلط OCR تأییدشده، ۳۷ کلمهٔ شکسته، ۲۴ تفاوت فاصله‌گذاری و
۱۰۲ نام کامل بررسی‌شده در `university-aliases.js` است. حرف‌های فارسی و شکل و
فاصلهٔ خط تیره نیز یکدست می‌شوند. جایگزینی عمومی «ال/لا» یا تطبیق حدسی انجام
نمی‌شود؛ «تالش» و «آل طه» درست هستند. واحدها، شمارهٔ شعبه، محل تحصیل، پردیس و
سایر مشخصات متفاوت حفظ می‌شوند.

در snapshot فعلی، ۱۰۳۳ صورت خام نام پس از اصلاح املا و هویت مؤسسه به ۴۷۱ نام
برای نمایش تبدیل می‌شود.
این اصلاح فقط هنگام خواندن داده اعمال می‌شود: شناسهٔ snapshot، فایل‌های اصلی،
snapshot فعلی ۴۱٬۷۴۲ رکورد و مجموع ظرفیت ۶۵۳٬۰۴۳ را نگه می‌دارد. شرایط پذیرش و یادداشت‌های
منبع نیز عیناً حفظ می‌شوند. برای نمونه، پزشکی دانشگاه علوم پزشکی گیلان به
جای دو ردیف جدا، در یک ردیف با ظرفیت‌های ۲۲۵، ۲۵۸، ۲۹۷ و ۳۴۷ برای سال‌های
۱۴۰۱ تا ۱۴۰۴ نمایش داده می‌شود.

## هویت مؤسسه در سال‌های مختلف و اصلاح استخراج

نام‌های کوتاه و بلند، توضیحات خوابگاهِ چسبیده به نام، و تغییر نام مؤسسه با
۲۱۸ نام جایگزین کاملِ بررسی‌شده در `university-identities.js` یکدست می‌شوند.
از حذف عمومی شهر، محل تحصیل یا نام پردیس استفاده نمی‌شود. تغییر نام آموزشکده
فنی‌وحرفه‌ای به ملی مهارت نیز برای هر آموزشکدهٔ مشخص جداگانه ثبت شده؛ شمارهٔ
شعبه و دختران/پسران حفظ می‌شود. تطبیق تبریز برای پزشکی/دندانپزشکی به‌صورت
جداگانه اعمال می‌شود و عنوان واحد دامپزشکی را تغییر نمی‌دهد.

۳۱ ردیف نام دانشگاهِ استخراج‌شدهٔ اشتباه دارند. اصلاح هر ردیف فقط با تطابق
سال، رشته، شناسه و صفحهٔ منبع، کدرشته‌محل، نام خام و ظرفیت اعمال می‌شود.
PDFها بصری بررسی شدند و هششان با `sources.csv` snapshot برابر است؛ پیوند و هش
سند همراه هر اصلاح ثبت شده است:

  استخراج شده؛ دانشگاه صحیح علوم پزشکی زابل است. دانشگاه اراک و علوم پزشکی
  اراک دو مؤسسهٔ جدا هستند.
- ۱۶ ردیف آزمایشگاهی/تغذیه با نام «استان خراسان رضوی» به وارستگان مشهد می‌رسند.
- آزمایشگاهی ۱۴۰۳ کد ۳۷۸۱۲ به علوم پزشکی ایران و ۱۳ ردیف آزمایشگاهی ۱۴۰۱ به

فهرست دانشگاه‌های قابل انتخاب از هویت اصلاح‌شدهٔ رکوردهای رشتهٔ دریافت‌شده
ساخته می‌شود؛ نام منسوخ یا نام استخراج‌شدهٔ اشتباه به‌عنوان گزینهٔ جدا باقی
نمی‌ماند. تا دریافت داده، انتخاب دانشگاه غیرفعال است؛ خطا و تلاش دوباره نمایش
داده می‌شود. snapshot خام همچنان عیناً حفظ شده است. نام‌های مبهم بدون شواهد
کافی با مؤسسهٔ دیگری ادغام نمی‌شوند.

## به‌روزرسانی صریح

```bash
CAPACITY_SOURCE_ROOT=/path/to/Entekhab-Reshte npm run data:capacity
npm run verify
npm run test:e2e
npm run check:cloudflare
npm run test:cloudflare
```

checkout منبع باید در commit موردنظر و بدون تغییر ثبت‌نشده در `data/capacity`
باشد. همگام‌ساز ابتدا فایل‌ها را با `git archive` از همان commit ثابت استخراج
می‌کند؛ تغییر بعدی checkout روی snapshot اثر ندارد. پس از به‌روزرسانی، انتظارهای ثابت قرارداد snapshot در تست، این گزارش و
README را با نسخهٔ بررسی‌شده هماهنگ کنید و خروجی‌ها را همراه کد commit کنید.

تست‌ها تطابق تمام فیلدهای هر ردیف snapshot با CSV نهایی، جدایی گروه‌ها، جمع
ظرفیت‌ها، پاسخ دیررس شبکه، خطا و تلاش دوباره، پاک‌شدن انتخاب‌های وابسته و
مسیر مستقل در Next و Workers را بررسی می‌کنند.
